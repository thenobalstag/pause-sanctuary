# PAUSE — A Small Place to Breathe

A cinematic relaxation web app built with React + Vite.

## Included in this upgrade

- Real ambience tracks from Mixkit for rain, forest, café and night ambience, with synthesized fallback for other layers.
- Richer cinematic environments with moonlight, water, fire, café windows and night-drive motion.
- Share PAUSE button using the native Web Share API, with clipboard fallback.
- Favicon, Apple touch icon, Open Graph/social preview image, canonical URL, robots.txt and sitemap.xml.
- Dedicated privacy page explaining current local-only storage and third-party audio loading.
- Mobile/responsive polish and reduced-motion support.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push the updated project to GitHub. Vercel will automatically create a new production deployment if the repository is already connected.
